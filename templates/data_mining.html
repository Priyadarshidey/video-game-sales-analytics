What kind of data mining is this?

The project applies predictive data mining - regression. Given historical records (platform, genre, publisher, year) the algorithms learn a mapping to a continuous numeric target, Global_Sales. The workflow follows the classic KDD steps: selection → pre-processing → transformation → mining (model training) → evaluation → using the knowledge (prediction).

  • Feature Engineering - what was selected, what was not
  • Linear Regression and Random Forest
