Why regional sales are not used as features

Global_Sales is (approximately) the sum of NA_Sales, EU_Sales, JP_Sales and Other_Sales. If the regional columns were given to the model it could simply add them up - this is target leakage, and the model would be useless for a game that has not been released yet. The current pipeline therefore predicts global sales only from information that is known before release: platform, genre, publisher and year. Name and Rank are identifiers (Rank is derived from sales, so it also leaks the target).
