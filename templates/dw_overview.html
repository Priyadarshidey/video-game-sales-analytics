What is a data warehouse? {{ impl('actual') }}

A data warehouse is a subject-oriented, integrated, non-volatile store of cleaned historical data designed for analysis rather than day-to-day transactions. In this project the subject is video game sales. The CSV is extracted, cleaned and loaded into a star schema so that sales (measures) can be sliced by game, platform, genre, publisher and year (dimensions) with simple joins.

Implemented in warehouse.py: extract() → transform() → load(). The database file is created automatically at start-up by ensure_warehouse(){% if etl.built_at %} (last built {{ etl.built_at }}){% endif %}.
