Fact table

The fact table records measurable business events. Fact_Sales holds {{ '{:,}'.format(s.total_records) }} rows. Its columns are five foreign keys (Game_ID, Platform_ID, Genre_ID, Publisher_ID, Year_ID) and five measures (NA_Sales, EU_Sales, JP_Sales, Other_Sales, Global_Sales), all in millions of units.

Dimension tables

A dimension table gives context to the facts. Each dimension stores every distinct value once with a surrogate integer key, which removes repeated text from the fact table (normalisation) and lets you filter or group by that attribute. Missing publishers/genres are stored as Unknown; missing years are stored as a NULL year member.
