Feature selection {{ impl('actual') }}

Selected features
Platform, Year, Genre, Publisher
Target
Global_Sales
Excluded
Rank, Name, NA_Sales, EU_Sales, JP_Sales, Other_Sales

Selection is done in train_model.py by keeping only ["Platform","Year","Genre","Publisher","Global_Sales"]. The regional sales are excluded to prevent target leakage (they add up to Global_Sales), and Name/Rank are identifiers.

Feature transformation {{ impl('actual') }}

  • Categorical → numeric: One-Hot Encoding creates {{ '{:,}'.format(meta.get('n_encoded_features', 0)) }} columns from Platform, Genre and Publisher.
  • Numeric scaling: Year is standardised with StandardScaler.
  • Missing values: imputed inside the pipeline (see Preprocessing).
Not implemented: the project does not create derived features such as game age, platform generation, publisher size or sales history. Those would be natural future work and could improve R², but they are not part of the current code.
