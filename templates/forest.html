What is Random Forest Regression?

A Random Forest builds many decision trees, each trained on a random bootstrap sample of the rows and considering a random subset of features at every split. For regression the forest's prediction is the average of all tree predictions.

How the trees are combined

Individual deep trees overfit, but their errors are partly uncorrelated, so averaging them (bagging) reduces variance while keeping the ability to learn non-linear effects and feature interactions.

Why it suits this dataset

Sales depend on combinations (a given publisher on a given platform in a given era) that a purely additive linear model cannot express, and the forest handles one-hot features without scaling. It also provides feature importance.
