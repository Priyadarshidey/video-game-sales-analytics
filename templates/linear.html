What is Linear Regression?

Linear Regression predicts a number as a weighted sum of the input columns: ŷ = b₀ + b₁x₁ + b₂x₂ + … + bₙxₙ. The weights b are chosen by ordinary least squares, i.e. to minimise the sum of squared differences between actual and predicted values on the training data.

Why it is the baseline

It is simple, fast and has no hyper-parameters. Any more complex model must beat it to justify its extra complexity. If a Random Forest barely improves on this baseline, the extra complexity is not buying much.

Each one-hot column gets its own coefficient, so every platform, genre and publisher contributes a fixed additive amount to the prediction. It cannot represent interactions such as "Shooter games sell better on PS3 than on DS". Predictions can be negative; the web app clips displayed predictions to 0.
