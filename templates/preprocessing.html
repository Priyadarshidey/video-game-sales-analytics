SimpleImputer

Replaces missing values with a statistic learned from the training data: most_frequent for the three categorical columns and median for Year (robust to outliers). Without it, scikit-learn estimators would raise an error on NaN.

OneHotEncoder

Turns each category into its own 0/1 column using handle_unknown="ignore", so a platform or publisher never seen during training produces all zeros instead of crashing the Flask app.

StandardScaler

Rescales Year to mean 0 and standard deviation 1: z = (x − mean) / std. It keeps the numeric feature on a scale comparable to the 0/1 columns, which matters for linear models.

ColumnTransformer

Applies the right transformation to the right columns in parallel: the categorical pipeline to Platform, Genre, Publisher and the numeric pipeline to Year, then joins the results into one feature matrix.

Pipeline

Chains preprocessing and the model into one object (Pipeline([("preprocessor", …), ("model", …)])). The pipeline is fitted on the training split only, which prevents data leakage from the test set, and the saved .joblib file applies exactly the same preprocessing at prediction time.

preprocessor = ColumnTransformer([
    ("cat", Pipeline([("imputer", SimpleImputer(strategy="most_frequent")),
                      ("onehot", OneHotEncoder(handle_unknown="ignore"))]), ["Platform","Genre","Publisher"]),
    ("num", Pipeline([("imputer", SimpleImputer(strategy="median")),
                      ("scaler", StandardScaler())]), ["Year"]),
])

Why is One-Hot Encoding required?

Regression algorithms do arithmetic on numbers. If "PS4", "Wii" and "PC" were mapped to 1, 2, 3 the model would wrongly assume PC > Wii > PS4 and that the "distance" between them is meaningful (ordinal encoding). One-hot encoding avoids this: each platform, genre or publisher gets its own binary column, so the model can learn a separate effect for each category with no artificial order. The trade-off is dimensionality - {{ di.n_publishers if di else 'many' }} distinct publishers alone create that many sparse columns.
